# MC Advisor — sito

Sito statico, pronto per GitHub Pages.

- `/` → sito MC Advisor (Mario Catini)
- `/emile/` → vetrina EMILE · Personal Organizer

## Pubblicazione
1. Carica questi file nella root del repository `mcadvisor`.
2. Su GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / root**.
3. Il sito sarà online su `https://mariocatini-cyber.github.io/mcadvisor/`
   (la vetrina su `.../mcadvisor/emile/`).

Dominio personalizzato (es. mcadvisor.online): in Settings → Pages → Custom domain, poi un record CNAME dal DNS verso `mariocatini-cyber.github.io`.

## Da completare in EMILE
Nel file `emile/index.html` sostituisci i segnaposto tra parentesi quadre:
`[Nome]`, `[Città]`, `[email@dominio.it]`, `[39XXXXXXXXXX]` (WhatsApp), `[profilo]` (Instagram), la presentazione e la foto.

## Logo
`assets/mc-logo.svg` è un monogramma provvisorio: sostituiscilo con il logo ufficiale MC Advisor mantenendo lo stesso nome file.
